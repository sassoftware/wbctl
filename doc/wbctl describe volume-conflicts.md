<pre>
Print detailed information about the Volume-Conflict resources identified by an optional list of resource ids. All resources printed if no ids provided.

Usage:
  wbctl describe volume-conflicts [flags]

Aliases:
  volume-conflicts, volume-conflict, workspace-conflict, workspace-conflicts

Flags:
  -h, --help   help for volume-conflicts

Global Flags:
  -m, --auth-mode string      Authentication mode. One of: device, pkce. (default "device")
  -e, --endpoint string       The Workbench API endpoint URL.
      --ignore-token-cache    Ignore token cache.
      --no-listen             Do not open a local port to listen for PKCE authentication.
      --organization string   The organization to authenticate with the Workbench API.
</pre>
