Prints a detailed description of one or many Workbench resources.

Usage:
  wbctl describe [command]

Available Commands:
  <a href='wbctl describe dataplanes.md'>dataplanes</a>       Describe one or many Dataplane resources
  <a href='wbctl describe image-builds.md'>image-builds</a>     Describe one or many Image-Build resources
  <a href='wbctl describe images.md'>images</a>           Describe one or many Image resources
  <a href='wbctl describe job-submissions.md'>job-submissions</a>  Describe one or many Job-Submission resources
  <a href='wbctl describe jobs.md'>jobs</a>             Describe one or many Job resources
  <a href='wbctl describe snapshots.md'>snapshots</a>        Describe one or many Snapshot resources
  <a href='wbctl describe users.md'>users</a>            Describe one or many User resources
  <a href='wbctl describe volume-conflicts.md'>volume-conflicts</a> Describe one or many Volume-Conflict resources
  <a href='wbctl describe volumes.md'>volumes</a>          Describe one or many Volume resources
  <a href='wbctl describe workbenches.md'>workbenches</a>      Describe one or many Workbench resources

Flags:
  -h, --help   help for describe

Global Flags:
  -m, --auth-mode string      Authentication mode. One of: device, pkce. (default "device")
  -e, --endpoint string       The Workbench API endpoint URL.
      --ignore-token-cache    Ignore token cache.
      --no-listen             Do not open a local port to listen for PKCE authentication.
      --organization string   The organization to authenticate with the Workbench API.

Use "wbctl describe [command] --help" for more information about a command.
